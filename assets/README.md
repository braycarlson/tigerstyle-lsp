# Brand Assets

## Overview

The artwork is named for where it is going rather than for the ink it happens to carry, so
a file is picked by its destination. A name ending `-on-light` sits on a light ground and a
name ending `-on-dark` sits on a dark one. A name carrying `-ground` supplies its own
opaque field and is placed on nothing.

## Colour

| Ink light | `#2A241E` |

## Type

| Face | Use |
|---|---|
| Bungee | The wordmark and the seal alone, set lowercase with tracking of −2%, and never body copy. |
| Archivo | The taglines, the headings, and prose. |
| JetBrains Mono | The code, the rule codes, the terminal output, and the labels. |

Each face is on Google Fonts.

## Clearspace

The margin around the lockup is half a seal on each side. Do not slant, stretch, rotate,
re-colour, or round the seal.

# TS037 no-abbreviations

The severity is info; the rule is opt-in by default and stable.

## Reports

A name spells its words out, because an abbreviation saves a few characters and costs each
later reader.

Reporting unit: Each name, and a name reports its first word in the table, or the name itself when
it is one or two letters long.

Anchor: The name token.

Carve-outs: The abbreviation table carries each entry with its expansion, `abs`, `acc`, `auth`,
`calc`, `desc`, `dir`, `env`, `gen`, `impl`, `info`, `init`, `iter`, `mod`, `spec`, and `sync` among
them, and the message names the expansion. A word TS042 reads as an acronym, such as `id`, `io`,
`os`, `fd`, or `db`, is the understood short form the standard keeps, the way TigerStyle writes
`VSRState`, so the table carries none of them and a two-letter name that is one is exempt. An
abbreviation whose expansion the language reserves is quiet, since the message asks for a name the
language rejects: Zig's `catch |err|` cannot become `error`, and a Go, Odin, Rust, or Zig `typ` or
`pkg` cannot become `type` or `package` where the language reserves the word. A word directly before
`keyword` spells that keyword, so `var_keyword` names `var` and is quiet. The name corpus is
declarations, fields, function names, parameters, JavaScript and TypeScript members and
object-literal keys, and Python `self.` attributes, not type names, and in Zig and Odin, where types
are values, a title-case name such as `comptime T: type`, Odin's `$T: typeid`, or `const Ext =
@FieldType(...)` and a name spelled like a primitive type, which is how a tuple field `struct { u32,
u8 }` reads, are type names. A field of an enum the file parses from text with
`std.meta.stringToEnum(Kind, text)` takes its name from that text, such as a grammar's own node
names, and is exempt. The underscores at both ends of a name are trimmed first. A Python name that
opens and closes with a double underscore, `__str__` or `__len__`, is a name the language reserves
for its data model, so it is the language's rather than the author's and is exempt. The words come
from the shared splitter, which cuts on underscores and on three camel boundaries: lower-to-upper, a
digit before a capitalized word, and the end of an uppercase run before a final lowercase word. The
name `HTTPServer` splits as `HTTP` and `Server`, and `Base64Encode` as `Base64` and `Encode`. A `v`
and a digit after an uppercase run are a version suffix and stay with the run, so `IPv4Address`
splits as `IPv4` and `Address`. A declaration whose value's trailing dotted segment equals the
declared name is a foreign alias and is exempt, and so is a Zig `const ir = @import("ir.zig");`,
whose name is the file's stem. The name may also match a dotted segment or a stem with its
surrounding underscores trimmed, so the private `_GetConsoleCursorInfo =
windll.kernel32.GetConsoleCursorInfo` keeps the foreign spelling; only the declared name is trimmed,
so `mgr = self._mgr` still reports, and a value with no dot must match whole, so `x = x_` reports
too. The whole name `init` is exempt because Zig and Go dictate it, while `init_buffer` reports. A
function declared inside a Rust `impl ... for ...` block is exempt, because the trait dictates its
name, and so is one under a header that wraps its `for` onto a later line: `fmt` in a `Display`
implementation is `core::fmt`'s word, not the author's, while a free `fn fmt` reports.

Go's `err` reports as an abbreviation of `error`. The standard names no idiom exception, and
the linter takes the standard over the idiom, as TS027 does for Go's `int`.

A name of one or two letters reports as too short to spell a word, since the standard's only
exemption is a primitive integer argument to a sort or matrix calculation. The exemptions are
the discard `_` and `__`, a two-letter English word (`at`, `by`, `do`, `go`, `if`, `in`, `is`,
`it`, `no`, `of`, `ok`, `on`, `or`, `so`, `to`, `up`, `us`, `we`), the variable a loop header
binds, which in Python includes a name inside a parenthesized target (`for i, (path, f) in ...`)
and a later assignment in the loop's body to a name the header bound (`v = mask(v)` under `for k, v
in items:`), and in Zig is the capture of `for (0..height) |y|` or `while (next()) |value|` while an
`if (item) |b|` capture and the `else |e|` capture after a loop still report, a name used as an
index inside `[...]` somewhere in its enclosing function, and a parameter of a function, or of a
lambda passed to a call, whose name contains `cmp`, `compare`, `dot`, `less`, `matrix`, `mul`,
or `sort`; a method call names its method, so the closure in `values.sort_by(|a, b| a.cmp(b))`
and the lambda in `values.sort(key=lambda a: a)` are passed to a sort. Go's one-letter receiver reports, as does JavaScript's `catch (e)`.

A Python stub, a `.pyi` file, restates a module the runtime defines, so a name it declares is the
runtime's spelling, fixed by that module as an `extern fn` name is by the linker, and is exempt:
`def getLevelName(level)` in `logging/__init__.pyi` and the keyword parameter `opt_str` of
`optparse.pyi` name what CPython names. A parameter before the `/` is positional only, a name no
caller spells, so it stays the stub's own and reports, and so does a declaration the stub marks
`@type_check_only`, which exists for the type checker alone.

## Does not report

The rule reaches every language tigerstyle-lsp lints.

A finding is suppressed by a `tigerstyle-ignore:` directive naming TS037, by a
`tigerstyle-file-ignore:` directive, or by a `tigerstyle-disable:` region covering the line.

## Known false positives

The shapes that misfire here are `destructure-single-name`, `macro-token-tree`, `type-switch-binding`, `composite-literal-key`, `type-argument-name`, `re-export-alias`, `bodiless-signature-name`, `bodiless-signature-parameter`, `empty-container-in-a-field-type`, and `go-signature-continuation`.

## Citations

TigerStyle: "Do not abbreviate variable names, unless the variable is a primitive integer
type used as an argument to a sort function or matrix calculation. Use long form arguments
in scripts: `--force`, not `-f`. Single letter flags are for interactive usage."

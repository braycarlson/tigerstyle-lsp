# TS042 acronym-case

The severity is info; the rule is opt-in by default and stable.

## Reports

An acronym keeps one case throughout a name, so `VSRState` reads as one word rather than two.

Reporting unit: Each name, and a name reports the first table word that mixes its case.

Anchor: The whole name.

Carve-outs: The table is `abi`, `ack`, `aes`, `api`, `ascii`, `cli`, `cpu`, `crc`, `css`, `csv`,
`db`, `dns`, `eof`, `fd`, `ffi`, `gc`, `gpu`, `html`, `http`, `https`, `id`, `io`, `ip`, `ipc`,
`jit`, `json`, `jwt`, `lru`, `lsm`, `mac`, `md5`, `nak`, `os`, `pid`, `ram`, `rpc`, `rsa`,
`sdk`, `sha`, `sql`, `ssh`, `ssl`, `tcp`, `tls`, `toml`, `ttl`, `udp`, `ui`, `uri`, `url`,
`utf`, `uuid`, `vsr`, `wal`, `xml`, and `yaml`. The name corpus takes in each type, function,
method, value, field, and parameter name. A screaming name is skipped. A word reports only when the
acronym in it carries both an uppercase and a lowercase letter, so `HttpClient` and `ParseJson`
report while `HTTPClient`, `parse_json`, `jsonParse`, and Go's lowercase `url` type pass: a
single-case spelling is one case throughout. A word is cut at its first digit run before the
lookup, and trailing digits are stripped, so `Utf8Reader`, `Crc32`, `Sha256`, and `IoUring`
report; a `v` left before stripped digits is a version letter and is stripped too, so
`Ipv4Address` reports with the rendering `IPv4Address`. The uppercase form is computed by
ASCII upcasing the acronym's letters alone, so a new entry cannot render as the wrong word and
the digits and version letter keep their case.

The fix renames the declaration and each use the file's binding table resolves to it, and only
where those are all the uses there are: a binding inside a function, or in Zig and Rust a
declaration without `pub` or `export`. A public declaration, a field, a method, and a top-level
name in a language whose other files share the namespace keep uses beyond this file or behind
member access, so they report without a fix, and so does a rename whose new spelling another
binding in the file already holds. The edits run in source order, so a use above the declaration is
renamed as surely as one below it. A Zig test that names the declaration, `test JsonValue {`, is a
use the binding table does not hold, and the fix renames it with the rest; when two declarations in
the file share the name, the test's target is ambiguous and the finding reports without a fix.

A Python stub, a `.pyi` file, restates a module the runtime defines, so a name it declares is the
runtime's spelling, fixed by that module as an `extern fn` name is by the linker, and is exempt:
`def getLevelName(level)` in `logging/__init__.pyi` and the keyword parameter `opt_str` of
`optparse.pyi` name what CPython names. A parameter before the `/` is positional only, a name no
caller spells, so it stays the stub's own and reports, and so does a declaration the stub marks
`@type_check_only`, which exists for the type checker alone.

## Does not report

The rule reaches every language tigerstyle-lsp lints.

A finding is suppressed by a `tigerstyle-ignore:` directive naming TS042, by a
`tigerstyle-file-ignore:` directive, or by a `tigerstyle-disable:` region covering the line.

## Known false positives

The shapes that misfire here are `acronym-at-a-use-site`, `acronym-behind-a-binding`, and `adapter-coverage`. A table word that is also an English word, such as `Mac` in `MacOs`, reports
as the acronym.

# TS039 else-if-chain

The severity is warning; the rule is on by default and stable.

## Reports

An `else if` chain carries at most `else_if_chain_max` conditioned arms, three by default,
so each case stays visible.

Reporting unit: Each chain, at its head.

Anchor: The chain's opening branch.

Carve-outs: The count is of conditioned arms: the head `if` and each `else if`, whether
spelled `else if`, `elif`, or as an `if` alone inside an unbraced `else`. A trailing `else`
is the default rather than a case and is neither counted nor credited, so four conditioned
arms report whether or not an `else` closes them. An arm that continues the chain is not
counted as a head of its own. A Zig arm opens with `else`: an `if` that is the then-body of
an arm, as in `else if (a) if (b) x else y else if (c) z`, is a nested branch rather than an
arm, so that chain counts three arms, not four.

## Does not report

The rule reaches every language tigerstyle-lsp lints.

A finding is suppressed by a `tigerstyle-ignore:` directive naming TS039, by a
`tigerstyle-file-ignore:` directive, or by a `tigerstyle-disable:` region covering the line.

## Known false positives

There are none recorded.

## Citations

TigerStyle: "Compound conditions that evaluate multiple booleans make it difficult for the
reader to verify that all cases are handled. Split compound conditions into simple
conditions using nested `if/else` branches. Split complex `else if` chains into `else { if
{ } }` trees. This makes the branches and cases clear."

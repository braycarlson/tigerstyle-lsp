# TS021 no-goto

The severity is error; the rule is on by default and stable.

## Reports

A jump to a label leaves control flow unstructured, so the reader cannot bound what runs
next.

Reporting unit: Each statement.

Anchor: The `goto` keyword.

Carve-outs: There are none. Each occurrence of the keyword reports.

## Does not report

The rule reaches Go. Python has no goto, and Rust and Zig have loop labels that break and
continue to an enclosing loop only.

A finding is suppressed by a `tigerstyle-ignore:` directive naming TS021, by a
`tigerstyle-file-ignore:` directive, or by a `tigerstyle-disable:` region covering the line.

## Known false positives

There are none recorded.

## Citations

TigerStyle: "Use only very simple, explicit control flow for clarity."

NASA P10 Rule 1: "Restrict all code to very simple control flow constructs — do not use
goto statements, setjmp or longjmp constructs, and direct or indirect recursion."

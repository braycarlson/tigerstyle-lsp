# TS018 no-complex-macros

The severity is warning; the rule is opt-in by default and stable.

## Reports

A macro stays small, because a reader cannot step through an expansion.

Reporting unit: Each macro definition, invocation, or procedural-macro attribute.

Anchor: The macro name, or the `proc_macro` attribute name.

Carve-outs: A token-pasting macro (`concat_idents`, `paste`) reports outright. A `macro_rules!`
definition reports when it spans more lines than `function_lines_max`, repeats with `$(`,
invokes itself, or invokes itself through other macros defined in the same file, which is a
cycle found over the file's first sixty-four `macro_rules!` bodies. An invocation through a path
names the macro its root reaches: `$crate::name!`, `crate::name!`, `self::name!`, and
`super::name!` stay in the crate and count, while `tracing::trace!` or `::log::trace!` inside a
macro named `trace` invokes another crate's macro and is no recursion. A function under
`#[proc_macro]`, `#[proc_macro_attribute]`, or `#[proc_macro_derive]` reports, because a
procedural macro is the unrestricted expander the rule confines.

A test table is quiet: a macro defined in test scope, read as TS016 reads it, which takes in a
test file by path, a `#[cfg(test)]` module, and a test function, whose expansion is test
functions, because its body holds a `#[test]` or `#[bench]` attribute or it invokes another
macro of the file whose body does, read over the same sixty-four bodies. Such a macro is the
list a test suite reads its cases from, not machinery a reader steps through, and the arm that
invokes the macro again to supply a default argument is part of the table. A test module is no
exemption for anything else: a long helper under `#[cfg(test)]`, or a recursive one inside a
test function, reports like any other, and so does a macro outside test scope that expands to
tests.

"All macros must expand into complete syntactic units" is enforced by the language rather than
the rule. A `macro_rules!` body is a token tree, so the compiler rejects an unbalanced
delimiter before the linter reads the file, and an expansion that is not a whole expression,
item, statement, type, or pattern is rejected at the invocation.

## Does not report

The rule reaches Rust. Go has no macro system, Python has none, and Zig has comptime rather
than a textual macro expander.

A finding is suppressed by a `tigerstyle-ignore:` directive naming TS018, by a
`tigerstyle-file-ignore:` directive, or by a `tigerstyle-disable:` region covering the line.

## Known false positives

There are none recorded.

## Citations

NASA P10 Rule 8: "The use of the preprocessor must be limited to the inclusion of header
files and simple macro definitions. Token pasting, variable argument lists (ellipses), and
recursive macro calls are not allowed. All macros must expand into complete syntactic
units."

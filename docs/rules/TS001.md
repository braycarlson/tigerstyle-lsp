# TS001 no-recursion

The severity is error; the rule is on by default and stable.

## Reports

A function does not call itself, so stack usage is bounded by the call graph rather than by
the input.

Reporting unit: Each function. A function that calls itself twice reports once, and a cycle through
the call graph reports at the entry the walk reached first.

Anchor: The call that closes the cycle where the function calls itself directly; the line the
function is declared on where the cycle runs through another function.

Carve-outs: A callee resolves by the text of its name, and the graph is keyed on that text rather
than on the declaration the name reaches. There are two consequences, and both stay. A call to a
macro, a builtin, or a function declared elsewhere that happens to share a name with a function in
the file closes a cycle that does not exist, which is what the ledger records as
`name-keyed-call-graph`. A method that delegates to another object's method of the same name records
an edge whichever object it is, so `c.parent.getOut(def)` inside `getOut` is a cycle here. Both are
recorded in `DEVIATIONS.md`, and the anchor is the call rather than the declaration, so a function
in both a direct and an indirect cycle reports once.

A function is any binding whose value is a function: a declared function or method, a class
method in JavaScript and TypeScript, a lambda bound by `const`, `let`, or `var`, and a Go
variable declared with a function type and later assigned a function literal. A method call
through `self`, `cls`, `Self`, or `this` resolves against the enclosing class or container,
and a call through a local container name, such as Zig's `S.step()` where `const S = struct {
fn step() ... }`, resolves to that container's member. A `comptime` function in Zig is exempt,
since the compiler evaluates it before the program runs, and so is a private function whose every
call outside its own body is a `comptime` expression, `return comptime processIncludes(...)`: no
other file can call it, and the compiler evaluates each call the file makes. A `pub` or `export`
function, or one the file also calls at run time, still reports.

A Rust method in an `impl Trait for Type` block whose first statement calls its own name before
anything can branch, `fn poll_accept(&mut self, cx) { Self::poll_accept(self, cx) }`, `unsafe {
Task::from_raw(ptr) }`, `Box::pin(Self::rename(self, from, to))`, `self.iter().copied()`, or `let
reader = Self::read(self, path).await?;`, delegates to the type's inherent method of that name and
is quiet: Rust resolves an inherent method before a trait method, and a method that calls itself
on entry, with no closure, branch, loop, `&&`, `||`, `?`, `return`, or macro ahead of the call,
could never return. The header may wrap its `for` onto a later line. The method must make no other
call the file resolves. A trait method that calls itself after a branch, as a `Future::poll` that
polls itself again after a state change, and an inherent method whose body is its own call, still
report.

A Rust call that cannot reach the function it names closes no cycle, where the function makes no
other call the file resolves: a method call, `context.upscaled_resolution()`, of a function that
takes no `self`; a call whose argument count differs from the function's parameter count, the
receiver counted on both sides, as `self.drain(..)` inside `fn drain(&mut self)`; and a call through
a path whose head is a type parameter of the function or its `impl`, `I::sort(&mut self.items)`
inside `impl<I: Sorted> Phase<I>`, unless the `impl` is for that parameter itself.

## Does not report

The rule reaches every language tigerstyle-lsp lints.

A finding is suppressed by a `tigerstyle-ignore:` directive naming TS001, by a
`tigerstyle-file-ignore:` directive, or by a `tigerstyle-disable:` region covering the line.

## Known false positives

The shapes that misfire here are `trait-impl-dispatch`, `cycle-reported-twice`, `bare-call-to-a-method`, `builtin-name-collision`, and `name-keyed-call-graph`.

## Citations

TigerStyle: "Use only very simple, explicit control flow for clarity. Do not use recursion
to ensure that all executions that should be bounded are bounded."

NASA P10 Rule 1: "Restrict all code to very simple control flow constructs — do not use
goto statements, setjmp or longjmp constructs, and direct or indirect recursion."

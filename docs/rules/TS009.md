# TS009 no-bare-except

The severity is warning; the rule is on by default and stable.

## Reports

An except clause names the errors it handles, so an unrelated failure is not swallowed with
them.

Reporting unit: Each handler.

Anchor: The `except` keyword.

Carve-outs: A handler reports when its keyword opens a statement and is followed straight away
by a bare colon, which is Python's `except:`, or by `BaseException`, which catches everything
the bare form catches, `KeyboardInterrupt` and `SystemExit` included, and so is the bare form
under another spelling. `except BaseException as error:` reports the same way. A handler that
names any other exception type passes; `except Exception:` passes here and is TS010's concern
when its body swallows.

Each finding carries a fix marked unsafe: the bare form gains `Exception`, and
`BaseException` is rewritten to `Exception`. The fix is unsafe because it changes which
errors the handler catches without changing what the handler does with them, so a run with
`--fix` leaves it alone and only `--unsafe-fixes` applies it.

The code also reads a handler as bare when the keyword is followed by a block opener, which
is the `catch {` of JavaScript, TypeScript, and Zig, but those cells are inapplicable and the
rule never runs there, so that arm has no effect in a lint run. A `catch` used as a property
key is not a handler in JavaScript or TypeScript, because a key is followed by a colon and
those languages do not spell a handler that way.

## Does not report

The rule reaches Python. Go and Rust have no exception handler, so there is no bare one to
catch; Go's `recover()` and Rust's `catch_unwind` are the panic-recovery shape and are
reported by TS052 no-panic-recovery. JavaScript and TypeScript have no typed catch: each
catch clause catches everything, so none is barer than another. Odin has no exception
handler; a procedure returns an error value beside its result. Zig has no exception handler;
an error union is returned, not caught.

A finding is suppressed by a `tigerstyle-ignore:` directive naming TS009, by a
`tigerstyle-file-ignore:` directive, or by a `tigerstyle-disable:` region covering the line.

## Known false positives

There are none recorded.

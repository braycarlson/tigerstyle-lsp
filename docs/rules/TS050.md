# TS050 unused-suppression

The severity is warning; the rule is on by default and in preview.

## Reports

A suppression directive that suppresses nothing is removed, so the file does not carry a
directive for a rule it does not break.

Reporting unit: Each directive.

Anchor: The directive comment.

Carve-outs: A directive naming a code tigerstyle-lsp does not carry reports as unknown. A directive naming several
codes, some live, keeps the live ones and the fix drops the rest. A `tigerstyle-enable:` that
closes no region reports.

## Does not report

The rule reaches every language tigerstyle-lsp lints.

A finding is suppressed by a `tigerstyle-ignore:` directive naming TS050, by a
`tigerstyle-file-ignore:` directive, or by a `tigerstyle-disable:` region covering the line.

## Known false positives

There are none recorded.

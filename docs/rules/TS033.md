# TS033 options-struct

The severity is warning; the rule is opt-in by default and stable.

## Reports

A pair of parameters of one type can be transposed at the call site, so the function takes a
struct whose fields are named instead.

Reporting unit: Each function, in a declaration, an anonymous function expression, or a
lambda bound to a name, and a function reports the first pair found. Each pair is compared, not
neighbours only: `f(start: u32, name: &str, end: u32)` reports `start` and `end`, since the
standard says a function taking two `u64`, not two adjacent ones.

Anchor: The span from the start of the earlier parameter to the end of the later one.

Carve-outs: A parameter carrying no spelled type is skipped. The comparison normalises the
type text so two spellings that differ only in whitespace still pair. A pair of parameters that
shares one declaration, as Go's `a, b int` and Odin's `a, b: int` do, pairs like any other,
because the call site is `f(1, 2)` either way.

A parameter after a bare `*` and a variadic parameter are exempt, since a keyword-only or variadic
argument cannot be transposed. A foreign signature is exempt, one on a line naming a boundary or
`foreign`, and so is a stub whose body is `...`. A `type` parameter is exempt, and so is a discard,
`_`, which carries nothing the function reads, including a Rust wildcard pattern `_: &'static str`
that binds no name; `_name` binds a name and still pairs. A TypeScript overload implementation is
exempt, the function with a body that follows bodiless signatures of the same name in the same
scope, since a call site binds to the overload signatures and never sees the implementation's
`first: any, second?: any`.

A function the file hands over as a value is exempt, because the function type it fills fixes its
parameter list: a comparator passed to a sort or a search, a function stored in a table of function
pointers, and a `std.mem.Allocator` vtable entry such as `.resize = resize`. The file hands a
function over when it names the function without calling it, by its own name or through its
container, as `Row.less_than` does, or when it writes the function in place as a call argument, a
field value, or the value of a member assignment such as `inst.run = function shim(first: any,
second: any)`, or when an anonymous container declares it and the file names it through that
container, `struct { fn either(first: Result, second: Result) Result {} }.either` passed as an
argument, with or without parentheses that wrap exactly the container. The position is read where
the container expression starts, so `const either = struct { ... }.either;` is an untyped alias and
the helper it binds reports like any function the file calls. An object literal's method,
`register(first: any, second: any) { ... }`, is declared under its own name and is not written in
place. A function passed beside a tuple of its own arguments, as in `std.Thread.spawn(.{}, work, .{
first, second })`, still reports, since that call fixes no parameter list and the tuple can
transpose the pair. An untyped alias such as `pub const build = run;`, a comparison, an export, and
an Odin procedure group `proc{first, second}` hand nothing over either, since none of them fixes a
parameter list, and a generic call such as `run::<T>(value)` is a call. A switch prong hands a
function over exactly when the switch itself would: a prong of a switch that is a field value, an
argument, or a return value fills the function type the switch fills, while a prong of a switch
bound to an untyped alias does not. A comparator shaped for a standard sort or a hash map context,
three parameters whose first has type `void` or `@This()` and a `bool` or `std.math.Order` result,
is exempt even where another file hands it over, since the interface fixes that shape.

## Does not report

The rule reaches Go, Odin, Python, Rust, TypeScript, and Zig. A JavaScript parameter
carries no type, so two parameters cannot be compared.

A finding is suppressed by a `tigerstyle-ignore:` directive naming TS033, by a
`tigerstyle-file-ignore:` directive, or by a `tigerstyle-disable:` region covering the line.

## Known false positives

There are none recorded.

## Citations

TigerStyle: "Zig has named arguments through the `options: struct` pattern. Use it when
arguments can be mixed up. A function taking two `u64` must use an options struct. If an
argument can be `null`, it should be named so that the meaning of `null` literal at the
call site is clear."

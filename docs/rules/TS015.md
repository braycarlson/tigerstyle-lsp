# TS015 no-lambda

The severity is warning; the rule is on by default and stable.

## Reports

A named function carries a name in the traceback, where a lambda carries none.

The rule is an inference rather than a quotation. The naming sentence asks for a verb that
says what a thing does, and an anonymous function has none; the control-flow guidance asks
that branching sit in one parent function with leaf helpers below it, and a function written
inline at its use site is the opposite shape. A lambda that is stored, keyed, or returned
therefore reports, and a lambda handed straight to the call that consumes it does not, since
that one is named by the parameter it fills.

Reporting unit: Each lambda expression.

Anchor: The lambda keyword, or, for an arrow function, the opening parenthesis of its
parameter list, the bare parameter, or the `async` before either.

Carve-outs: A lambda passed straight to a call, a `defer`, or a `go` statement is exempt, since
it is invoked where it is written, and so is an immediately invoked one, whether the call follows
its body, as Go's `func() { ... }()` does, or follows the parentheses that hold it, as `(|| {
... })()`, `(function () { ... })()`, and `(lambda: 1)()` do; a lambda wrapped in parentheses
that nothing calls still reports. A pair of parentheses that wraps exactly one lambda and stands
as a whole argument is grouping, so `iter((lambda: cursor.fetchmany(size)), sentinel)` passes
the lambda straight to `iter`, while `(|x| x + 1).pipe(other)` calls a method on the closure and
`fn ?? (() => true)` makes it an operand, and both still report. A function type inside a
signature or a type is a type rather than a lambda, and is exempt too. A Rust `||` that
follows a value, which is a name, a literal, a closing bracket, `self`, `?`, or `.await`, is
the or operator rather than an empty parameter list and is not read as a lambda.

JavaScript and TypeScript report an arrow function under the same checks as a `function`
expression: one bound by `const`, `let`, or `var`, stored in a collection or an object
literal, assigned to a property such as `element.onclick`, or exported reports; one passed
straight to `map`, `then`, `setTimeout`, or any other call, and one invoked in place, is
quiet. An arrow inside a type annotation, an interface member, or a `type` alias is a type.

Odin reports a procedure literal bound by `:=`, such as `step := proc(v: int) -> int { ... }`,
since the variable holds an anonymous procedure; a procedure declared by `::` is a named
procedure and is quiet.

## Does not report

The rule reaches Go, JavaScript, Odin, Python, Rust, and TypeScript. Zig's anonymous
function is a named `fn` on an anonymous struct, `struct { fn lessThan(...) ... }.lessThan`,
which TigerBeetle itself writes 145 times as the comparator idiom; the naming sentence the
rule infers from is met by the `fn` name, so the shape is not reported and the cell stays
inapplicable.

A finding is suppressed by a `tigerstyle-ignore:` directive naming TS015, by a
`tigerstyle-file-ignore:` directive, or by a `tigerstyle-disable:` region covering the line.

## Known false positives

The shapes that misfire here are `macro-token-tree`, `argument-closure-return`, and `nested-literal-anchor`.

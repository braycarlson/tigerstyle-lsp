# TS007 no-dynamic-exec

The severity is error; the rule is on by default and stable.

## Reports

No code is built and run at runtime, because nothing can be checked before it executes.

Reporting unit: Each call site.

Anchor: The callee name, or the head of its path where the callee is qualified.

Carve-outs: A bare callee reports when its name is watched and an opening parenthesis follows it, so a
variable of the same name is quiet, and so is a function the file declares under that name, `def
eval(self, context):`, whose parenthesis opens a parameter list rather than a call. Python watches `__import__`, `compile`, `eval`, and
`exec`; JavaScript and TypeScript watch `Function` and `eval`, so `new Function(text)` and
`eval(text)` report. The indirect form `(0, eval)(text)` reports at `eval`.

A dotted callee reports when the whole path is watched, and the paths are exact. Python
watches `builtins.__import__`, `builtins.compile`, `builtins.eval`, `builtins.exec`,
`importlib.__import__`, and `importlib.import_module`; JavaScript and TypeScript watch
`globalThis.eval`, `globalThis.Function`, `self.eval`, `self.Function`, `window.eval`,
`window.Function`, `vm.Script`, `vm.compileFunction`, `vm.runInContext`,
`vm.runInNewContext`, and `vm.runInThisContext`. Any other dotted callee is quiet, which
keeps `re.compile` and `json.loads` out. A pickle load is quiet too: `pickle.loads` and
`pickle.load` restore a value from data rather than assemble code from a string, since a
pickle can only name callables that already exist as code, so the round trip
`pickle.loads(pickle.dumps(value))` builds nothing.

A string evaluated at runtime reports however it was built, since P10 Rule 10 makes no
exception for code the analyser never reads: `eval(repr(xx), dict(array=np.array))` and
`eval("(o) => %HasFastProperties(o)")`, whose V8 natives syntax no module body can hold,
both report.

A timer reports when its first argument is a string literal or a template literal, since
`setTimeout("run()", 0)` and `setInterval(`run()`, 0)` compile that string at runtime. A
timer given an identifier is quiet, because the linter cannot tell a string variable from a
function by name.

A call inside a test reports like any other; no standard exempts test code from the analyser.

## Does not report

The rule reaches JavaScript, Python, and TypeScript. Go, Odin, Rust, and Zig have no eval
or exec; there is no runtime string-to-code path to report.

A finding is suppressed by a `tigerstyle-ignore:` directive naming TS007, by a
`tigerstyle-file-ignore:` directive, or by a `tigerstyle-disable:` region covering the line.

## Known false positives

There are none recorded.

## Citations

NASA P10 Rule 10: "All code must be checked daily with at least one, but preferably more
than one, state-of-the-art static source code analyzer and should pass the analyses with
zero warnings." The code assembled from a string at runtime is never seen by the analyser,
so the rule reports the call that assembles it.

# TS054 run-to-completion

The severity is info; the rule is opt-in by default and stable.

## Reports

A function that has asserted does not suspend, so what it asserted still holds when the next line
runs.

Reporting unit: Each suspension point.

Anchor: The suspending keyword, or the name of the suspending method.

Carve-outs: A suspension point is the keyword `await` or `yield` in JavaScript, TypeScript, Python,
and Rust, where Rust's is the `.await` postfix, so an `await` without the member dot, such as the
token kind a parser names with `T![await]`, suspends nothing. The Zig 0.17 language has no
`await` keyword, so its suspension points are the `suspend` keyword and a call of a method named `await`, which is how
`std.Io` waits on a `Future` or a `Group` (`try group.await(io)`). The rule reports when an
assertion appears earlier in the same function, read from the function's first token to the
suspension point, because the assertion then documents a precondition the suspension may invalidate.
A suspension point before any assertion is quiet, as is a function that never asserts. An
assertion inside a block that ends by returning, raising, or throwing, and that does not hold the
suspension point, runs on a path that leaves before the suspension: `if context is not None:` with
`assert context.app is not None` and a `return` at its end asserts nothing for an `await` after the
branch.

There are three kinds of assertion written before the suspension that do not run before it. An
assertion inside a closure that does not also hold the suspension runs when the closure is called,
so the `unreachable!()` of `s.acquire(1).await.unwrap_or_else(|_| unreachable!())` is not one; an
assertion in an `async` block counts, since awaiting the block runs it up to its first suspension.
An assertion whose own arguments hold the suspension, `assert_eq!(Some(1), stream.next().await)`,
checks the value the suspension produced. A Zig assertion under `comptime`, `errdefer comptime
unreachable;`, is a compile-time proof with nothing left to invalidate at run time.

A comment, a string, or a number that spells one of the words is not a suspension point, and
neither is a name: a JavaScript property such as `task.await`, or a Zig enum literal such as
`.await`, which is no call.

## Does not report

The rule reaches JavaScript, Python, Rust, TypeScript, and Zig. Go has no suspension point inside
a function; a goroutine blocks on a channel, but the function's own control flow never yields to
its caller. Odin has no async, await, or coroutine; a procedure runs to completion.

A finding is suppressed by a `tigerstyle-ignore:` directive naming TS054, by a
`tigerstyle-file-ignore:` directive, or by a `tigerstyle-disable:` region covering the line.

## Known false positives

There are none recorded.

## Citations

TigerStyle: "Ensure that functions run to completion without suspending, so that precondition
assertions are true throughout the lifetime of the function. These assertions are useful
documentation without a suspend, but may be misleading otherwise."

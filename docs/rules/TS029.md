# TS029 four-space-indent

The severity is info; the rule is on by default and stable.

## Reports

The indentation is four spaces per level, with no tabs, so a file reads the same everywhere.

Reporting unit: Each line; each offending line reports, including each line after a tab.

Anchor: The leading whitespace, or the tab where one stands.

Carve-outs: A line carrying a string token or a comment token is exempt, which covers a raw string, a
doc comment, and a continuation line that opens with a string; a line whose first non-space
character is `*` is exempt too, as a block-comment continuation.

A line inside a `macro_rules!` body is exempt, since the template's indentation is the macro's
own.

A line inside an open bracket whose first token stands in the column of the bracket's first
element, written on the bracket's own line, continues that element's list rather than opening a
level, so `validator: None = ...,` under `default` in `def attrib(default: None = ...,` is quiet.
A bracket that ends its line opens a hanging list whose lines are indented by levels, so a
hand-aligned table under `const CLASSES: [u8; 256] = [` still reports, and so does a line that
stands one column short of the first element.

Go and Odin are indented by their own formatters, gofmt and odinfmt, and both indent with
tabs, so for those two languages the four-space clause yields to the formatter: a tab is one
level, and a line whose leading whitespace carries a space reports, since it is wrong under
both the formatter and TigerStyle. The indentation is the formatter's decision, and the formatter
runs on each file; a name is a choice no formatter makes, which is why TS032 does not yield to
gofmt's MixedCaps.

## Does not report

The rule reaches every language tigerstyle-lsp lints.

A finding is suppressed by a `tigerstyle-ignore:` directive naming TS029, by a
`tigerstyle-file-ignore:` directive, or by a `tigerstyle-disable:` region covering the line.

## Known false positives

The shape that misfires here is `continuation-line-indent`.

## Citations

TigerStyle: "Use 4 spaces of indentation, rather than 2 spaces, as that is more obvious to
the eye at a distance."

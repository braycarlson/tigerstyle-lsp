# TS056 bounded-queues

The severity is warning; the rule is opt-in by default and stable.

## Reports

A queue carries a fixed capacity, so a producer that outruns its consumer fails at the bound rather
than growing without limit.

Reporting unit: Each constructing call.

Anchor: The whole call.

Carve-outs: A call reports when its callee, read with any leading `pkg.` or `module.` qualifier and without
a turbofish, names a queue that grows without limit: Rust `VecDeque::new`,
`VecDeque::with_capacity`, `BinaryHeap::new`, `BinaryHeap::with_capacity`, `LinkedList::new`,
`channel`, `unbounded`, and `unbounded_channel`; Python `Queue`, `LifoQueue`, `PriorityQueue`,
`SimpleQueue`, and `deque`; Zig `std.fifo.LinearFifo`, `std.PriorityQueue`, and
`std.PriorityDequeue`; Odin `queue.init`. A call on the result of such a call, such as the `.init`
after a Zig `LinearFifo(u8, .Dynamic)`, is not a second site.

A call is bounded, and quiet, when an argument is a number other than zero, so `channel(32)`,
`Queue(10)`, `queue.init(&held, 16)`, and `VecDeque::with_capacity(16)` pass, or when an argument
carries a bound word the language spells: Python `maxsize` with a value other than `0` or `None`,
`maxlen` with a value other than `None`, and Zig `.Static` or `.Slice`. A `Queue(maxsize=0)` grows
without limit, while `deque(iterator, maxlen=0)` holds nothing, which is how Python consumes an
iterator. A queue in test scope is exempt, as it is for TS016. A
Rust channel built through a `oneshot` or `watch` path, `oneshot::channel()` or
`watch::channel(initial)`, holds one value and is quiet: a watch channel keeps only the latest value
sent, so its argument is that value rather than a capacity. A Zig queue type named behind a
pointer, a field `queue: *std.PriorityQueue(T, Context, less)` or `*const std.PriorityQueue(...)`,
refers to a queue built elsewhere rather than building one, and is quiet. A Rust method call,
`self.channel.take()` or `self.channel.as_ref()`, calls a method of its receiver rather than one of
the listed paths and functions, since Rust spells a module path with `::`, and is quiet. A bare call
of a name the file declares as a function outside any container, `channel()` under `pub fn
channel() -> String`, calls that function rather than a queue constructor, and is quiet.

## Does not report

The rule reaches Odin, Python, Rust, and Zig. A Go channel is bounded by construction:
`make(chan T, n)` names the bound and an unbuffered channel holds nothing. JavaScript and
TypeScript have no queue type; an array used as a queue grows on push, which TS016 reports.

A finding is suppressed by a `tigerstyle-ignore:` directive naming TS056, by a
`tigerstyle-file-ignore:` directive, or by a `tigerstyle-disable:` region covering the line.

## Known false positives

There are none recorded.

## Citations

TigerStyle: "Put a limit on everything because, in reality, this is what we expect—everything
has a limit. For example, all loops and all queues must have a fixed upper bound to prevent
infinite loops or tail latency spikes."

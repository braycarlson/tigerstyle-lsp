# TS051 pointer-depth

The severity is warning; the rule is opt-in by default and stable.

## Reports

A pointer points at a value rather than at another pointer, so each access is one dereference a
reader can follow.

Reporting unit: Each type occurrence, plus one per double dereference in an expression.

Anchor: The type node, or the two dereference tokens.

Carve-outs: A type counts its leading pointer layers: each sigil the language spells (Go `*`, Rust
`*const`, `*mut`, `&`, and `&mut`, Zig `*`, `[*]`, and `[*c]`, Odin `^` and `[^]`), with `const`,
`mut`, `volatile`, `allowzero`, a Rust lifetime, and a Zig `?` skipped between them. A type with two
or more layers reports, so `**T`, `*const *const T`, `&&T`, `&mut &mut T`, `?*?*T`, `*[*]T`, and
`^^T` all report, while `*[]T`, `[]*T`, and `&[&str]` do not: a slice or an array between the sigils
is an index, not a dereference. A type nested inside a reported type is not reported again. An
expression reports when it dereferences twice in a row: Go and Rust `**value`, Zig `value.*.*`, and
Odin `value^^`. A Go `a * *b` is a product and is quiet; the pair is a type only when the name
before it is a parameter, a `var`, a `const`, or a field.

A line that marks a platform boundary is exempt, as it is for TS019: Zig `callconv`, `export`,
`extern`, and `opaque`, and Go `Call` and `Syscall`. The exemption also covers each line of a
function signature that carries a marker on any of its lines, such as a C ABI out parameter in a
signature whose `callconv(.c)` sits on the closing line, and each line inside a block whose opening
line carries one, such as an `opaque {` container. A chain through a field, such as
`value.*.next.*`, is not counted, since each step names the thing it reaches.

## Does not report

The rule reaches Go, Odin, Rust, and Zig. JavaScript, Python, and TypeScript have no
pointer type; each name binds a reference the runtime owns.

A finding is suppressed by a `tigerstyle-ignore:` directive naming TS051, by a
`tigerstyle-file-ignore:` directive, or by a `tigerstyle-disable:` region covering the line.

## Known false positives

There are none recorded.

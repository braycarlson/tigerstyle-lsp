# TS005 no-mutable-globals

The severity is error; the rule is on by default and stable.

## Reports

The global state is immutable, so no two parts of the program race to own it.

Reporting unit: Each declared name. A grouped declaration reports once per name inside the group.

Anchor: The declaring keyword, or the name where a group names several.

Carve-outs: Rust reports `static mut` and a `static` whose type is interior-mutable: `Cell`,
`Mutex`, `RefCell`, `RwLock`, `UnsafeCell`, or an `Atomic*`, anywhere in the annotation, so an array
or a generic of one counts, and a `struct` declared in the same file whose fields spell one of those
types counts too, one level deep. A `OnceLock` or `LazyLock` is quiet on its own, because the value
is written once, and reports when its type argument is interior-mutable, because
`OnceLock<Mutex<_>>` is a mutex reached through a write-once cell. Zig reports `var` and not
`const`. Go reports each `var`, whatever its name, since a variable is mutable however it is
spelled; only the blank identifier `_` is exempt, because it binds nothing. JavaScript and
TypeScript report `var` and `let` at module level, and a module-level `const` whose value is an
array literal, an object literal, or an allocation such as `new Map()`, `new Set()`, `Array()`,
`Map()`, `Set()`, `WeakMap()`, or `WeakSet()`, since `const` freezes the binding and not the object;
a value wrapped in `Object.freeze(...)` is quiet.

Python reports a module-level binding, including an augmented assignment, when the target is a
bare identifier and the module can be seen to mutate it: a name bound to a mutable literal, a
comprehension, or a mutable constructor reports whatever its name, `Final` and a screaming or
underscored spelling included, because neither freezes a list; a name a `global` statement
rebinds from inside a function reports; a name bound twice or more at module level outside a
branch or a handler reports; and a name a function mutates through a method such as `add`,
`append`, `pop`, or `update` reports. A binding to a call, an instance, or a scalar that is
never rebound or mutated is quiet, as is a name annotated `Final` or `TypeAlias` over an
immutable value, a type expression such as `str | None` or a tuple of type names, and a safe
module-level call such as `TypeVar`, `getLogger`, or `re.compile`. Odin reports each
module-level declaration that is not a constant: `count: int = 0`, `count := 0`, and
`@(private) count: int = 0` are variables and report, and `COUNT :: 0` is a constant and
passes, whatever the name or the value, because the language spells the distinction itself.

## Does not report

The rule reaches every language tigerstyle-lsp lints.

A finding is suppressed by a `tigerstyle-ignore:` directive naming TS005, by a
`tigerstyle-file-ignore:` directive, or by a `tigerstyle-disable:` region covering the line.

## Known false positives

The shapes that misfire here are `go-global-declaration-shape` and `blank-identifier-binding`.
A Rust `static` whose type is a struct that only reaches a `Cell` through a second struct is
not resolved, since the field walk is one level deep.

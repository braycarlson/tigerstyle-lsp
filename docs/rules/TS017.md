# TS017 check-return-value

The severity is warning; the rule is opt-in by default and stable.

## Reports

A returned value is used, because a call made only for its effect hides the result it also
produced.

Reporting unit: Each expression statement.

Anchor: The expression statement, not the call inside it.

Carve-outs: The callee is read from the call's `Name` child, so `Type::new()` resolves as
`Type::new` rather than as any same-named function in the file. A file-local function is judged by
its own signature; a foreign one by the per-language tables, and an unknown callee stays silent, as
a call of the value another call returns, `getattr(data, name)()`, names none. A Zig signature is
read past the `callconv`, `align`, `addrspace`, and `linksection` groups between its parameter list
and its return type, so `fn write(value: u32) callconv(.c) void` returns nothing and a bare
`write(1);` is quiet, while the same signature returning `u32` reports. The exemption ladder is per
language: a void-call list per language, which excludes Go's `fmt.Print*` and `fmt.Fprint*` family,
since each returns a byte count and an error that P10 says to check or cast away with `_, _ =`; void
method names, which are Rust's twenty-four in-place mutators and Python's list of in-place and
lifecycle methods; Rust's checked methods `expect`, `expect_err`, `unwrap`, and `unwrap_err`; a
value-name table per language, which is the standard-library signature table the void list mirrors
(Go `fmt.Sprintf`, `fmt.Errorf`, `strings.TrimSpace`, `os.Getenv`, `strconv.*`, and `filepath.*`;
JavaScript and TypeScript `fetch`, `JSON.parse`, `parseInt`, and `Object.keys`; Python `open`,
`sorted`, `len`, `subprocess.run`, and `input`; Odin `pop`, `len`, `strings.trim_space`, and
`fmt.tprintf`); value method names (Rust `insert`, `remove`, `pop`, `next`, `take`, `replace`,
`write`, `flush`, `min`, `max`, `map`, `mem::replace`, and the `checked_*` family; Python `get`,
`pop`, `read`, and `setdefault`; JavaScript `pop`, `shift`, `delete`, `has`, and `toString`), with
Go carrying a second niladic list that applies only to a call taking no arguments; and Python's
dynamic-exec and safe-module-level lists. The explicit discard, `_ =` or `let _ =`, is the cast to
void that P10 allows, and the fix inserts it. Go and Odin assign one blank per value the callee
returns, so their fix writes `_, _ =` for a callee of two values. It reads the count from the
signature of a file-local function called without a receiver, or from the value-name table, whose
two-value names are listed apart (Go `fmt.Println`, `fmt.Fprintf`, `strconv.Atoi`, and
`os.LookupEnv`; Odin `pop_safe`, `strconv.parse_int`), and a call whose value count neither gives
keeps its finding without a fix: a method matched by name alone, `builder.WriteString(s)`, could
reach a type whose method returns one value or two.

A callee whose signature returns the never type, Rust and Odin `!`, Python `NoReturn` or `Never`,
or TypeScript `never`, returns no value at all, so a call of it discards nothing and is quiet, as
`fail()` under `fail :: proc() -> ! { panic("stop") }` is, while the sibling `one()` that returns an
`int` reports.

A fixture file is exempt: one under a snapshot or `testdata` directory, or one under a `test`,
`tests`, `__tests__`, or `spec` directory that holds no test of its own, which is a formatter
or highlighter input rather than a test. A file holds a test when it carries `#[test]`,
`cfg(test)`, or `@(test)`, a `test` block, a function whose name opens with `test`, `Test`,
`bench`, or `Benchmark`, or a callback handed to `test`, `it`, `describe`, or `bench`.

A method call resolves its method name rather than its receiver, so `stats.add(1)` is judged on
`add` and never on a function named `stats` elsewhere in the file; a package-qualified call
such as Odin's `strings.trim_space(s)` is also matched on its full spelling against the
value-name table.

The rule ships opt-in because its residue is the unknown callee. A call into a dependency
whose signature the linter never sees is silent, and a value-returning library function outside
the table is silent, so the rule under-reports; it is turned on once a project has put its own
library surface into the conventions tables.

A Rust call with no receiver and no path, `write_help(&mut styled, self, &usage, false);`, cannot
reach a method that takes `self`, so a file-local method of that name says nothing about what the
call returns.

## Does not report

The rule reaches every language tigerstyle-lsp lints.

A finding is suppressed by a `tigerstyle-ignore:` directive naming TS017, by a
`tigerstyle-file-ignore:` directive, or by a `tigerstyle-disable:` region covering the line.

## Known false positives

The shapes that misfire here are `void-standard-callee` and `composite-literal-element`.
